# 今天怎么穿 v1.0.0

本项目为独立实用穿搭网站；旧character-studio保留互动摄影棚方向。用户已确认当前界面，并授权独立正式发布。仅调整首页路径、正式标签、旧站链接和独立存储名称；衣服合成算法、人物及全部运行素材沿用已验证版本。

## 能力和边界

- 三角色、50设计/90原坐标适配，单日建议、单件换装、锁定再搭、已有单品偏好、保存重开。
- 1—7天旅行逐日搭配、复用/不复用和去重行李；摄影棚/生活背景、光线、照片/清单/方案下载。
- 吴心媛开心笑、鼓脸、独立眨眼；另两人独立眨眼。比心及两人旧肢体动作含固定服装，暂不兼容；真实禁用并保留目录、原始项目及素材。没有新生成动作或整图摇晃替代。
- 独立眼部PNG；初次失败可单独重试，眼外、衣鞋包及搭配状态不改变。照片无字。
- 收藏仅在使用者自己的浏览器。未实现账号同步、实时天气、购物、真实身材尺寸或上传服装自动适配。真实iPhone/安卓/微信尚未实机验收。
